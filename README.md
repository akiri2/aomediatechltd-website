# AOMEDIA TECH Ltd: static website (v2)
Professional, mobile-friendly redesign of the starter. Open `index.html` to preview.
## What to edit
Only the top block of `script.js`: phone, WhatsApp, social URLs, management, board, news/events. Empty items are hidden automatically. Services are listed in the same file.
## Publish
Follow `DEPLOY_TO_RENDER.md` (Render Static Site, publish directory `.`).
## Limits of this version
The contact form opens the visitor's email app (no server). Online booking with payments (MTN, Airtel, card, bank) and the admin dashboard need the backend project (`aomedia-tech.zip`).
Add real photos, logo, favicon, and privacy/terms pages before launch.
