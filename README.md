# AOMediaTech Ltd — website starter

A responsive, premium black-and-gold static website starter built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and editable company content
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation, current year and demo contact form behavior

## Preview locally
1. Extract the ZIP file.
2. Open the `index.html` file in a modern browser.
3. For a more realistic local development workflow, open the folder in Visual Studio Code and use the Live Server extension.

## Before publishing
1. Replace placeholder contact details with the company's real email, telephone, WhatsApp and address.
2. Confirm the exact registered company name, service descriptions and portfolio permissions.
3. Connect the contact form to a backend or trusted form service. The current form is a front-end demo and does not send email.
4. Add real project photos, approved client logos and testimonials only when you have permission.
5. Add a favicon, Open Graph sharing image, privacy notice and any relevant terms.
6. Test on mobile, tablet and desktop; check links, form delivery, accessibility, performance and SEO.
7. Purchase a domain and hosting. Point the domain's DNS to the selected hosting provider and enable HTTPS.
